# OSTA design system

Живу сторінку з усіма станами дивись на `/design-system.html` (`npm run dev`, порт 5173). Код: `src/styles/tokens.css` (єдине джерело значень), `base.css` (типографіка, іконки), `layout.css`, `components/*.css`. Сторінки збираються з готових класів, нового CSS-значення поза токенами писати не можна.

## Шрифт
Asta Sans, файли `public/assets/fonts/AstaSans-{Light,Regular,Medium}.woff2` (з `fontslibrary/`, оригінал не змінено). Medium (500) ЛИШЕ для `display / h1 / h2 / h3` та `.t-lead--medium` (імена); решта (абзаци, лінки, кнопки, мітки, пункти меню, кружки номерів) = Regular (400), жодних локальних `font-weight: 500`. Light (300) у розмітці не використовується (файл підключено). **SemiBold, Bold, ExtraBold у системі не використовуються** (не підключені). Fallback: `system-ui, sans-serif`.

## Кнопки: hover (ПРАВИЛО замовника 2026-11-13, категорично; гейт `npm run audit:hover`)
**КОЖНА кнопкоподібна сутність має диск-hover «з центру»** — без винятків «бо це хедер/фільтр/мова». Кнопкоподібна = клікабельний елемент із заливкою, контуром або pill-формою, або з класом `.btn*`, `.round-btn*`, `.icon-ring--action`, `.nav-pill`, `.lang-switch`, `.lang-menu__option` (десктопний випадний список і бургер), `.header__burger`, `.filter-item`, `.catalog__filters-toggle`, чипи, пагінація, вкладки. Не кнопка (текстове посилання: лише колір/підкреслення, без диска, але видимий hover ΔE ≥ 10; whole-card/медіа-посилання: hover компонента) — все одно гейтиться на видимий hover.
Механіка ОДНА (`buttons.css`, блок «DISC» + H1a): `::before`-диск, `scale 0 → 1` з центру, `--dur-hover-disc` (800 мс), `--ease-out`, лише `@media (hover: hover)`, reduced-motion миттєво, `isolation:isolate; overflow:hidden`; змінні ролі `--_hole` (колір диска) і `--_fg` (колір тексту/іконки в кінці). Новий елемент = додати селектор у список ролі, а НЕ писати власний hover (nav.css/сторінки лише задають змінні ролі).
**Однакова швидкість покриття (замовник 2026-11-13, правило B2b):** диск = коло, що щойно накриває кнопку (`--_cover`: довгі = діагональ мінус заокруглення, круглі = діаметр) × `--disc-overscan` (1.35), тому кнопка повністю накрита за той самий час (≈0.28–0.30 с з 0.8 с) для ВСІХ форм; колір стрілки/тексту, рамка, іконка й зсув натискання рухаються РАЗОМ з диском: `--dur-hover-color` = `--dur-hover-disc` (800 мс), затримки 0 (`--delay-hover-color-in/-round-in`), крива `--ease-hover` (замовник 2026-11-13: ОДИН темп hover для всіх інтерактивних: кнопки, поля, пункти шапки, мова, бургер, split-кнопки, картки; жодних 60/150/200/250 мс у hover); гейт `audit:hover` міряє час покриття (±10% від медіани).

## Typography: перенос рядків
Перенос рядків контролюємо граматично: у великому тексті (display, h1, h2, лід, цитати) ставимо ручний `<br>` (Shift+Enter) на межі речення чи фрази через `data-i18n-html` (ключ у `en.json`); службові слова й початок нового речення не лишаємо в кінці рядка. `text-wrap: balance` для заголовків, `pretty` для абзаців (задано в `base.css`).
Заголовок з одним реченням без кінцевої крапки; з кількома реченнями — крапки між реченнями.

## Токени
- **Правило кольору тексту:** заголовки й імена акцентні (`--text-accent` #0A3782), підзаголовки/мітки й абзаци темно-сині (`--text` = `--c-blue-950` #061f52; чорного на сайті немає, `--c-ink-900` видалено); сірувато-бірюзового тексту в системі немає. `--border` = blue-700 14%, `--border-strong` = `--c-blue-400`. `.btn--secondary` = контурна акцентна; «Chat with manager» = `.btn--primary`.

## Ілюстрації: єдиний рушій `src/utils/il-scene.js` (рішення замовника 2026-11-13)
**Усі нові three.js-сцени (Home, About, Services, Product) будуються на `src/utils/il-scene.js`; копіювати рендерер/probe/observer-код у сторінки заборонено** (одне визначення). Рушій дає: ОДИН `WebGLRenderer` на секцію (offscreen canvas) і копію кадру в 2D-canvas кожного слота (1 контекст на секцію, ліміт сторінки ≤4), токени `--il-fill/--il-soft/--il-bg` через probe-span, опакові премікс-лінії `kit.lineMat(a)` (рівно 1 device px), плоскі круглі точки `kit.dot.*`, заливку `kit.fillMat` + `kit.occluder`, поле точок-підлогу `kit.floor()` (`FLOOR_Y`/`FLOOR_LIFT`: рухаємо об'єкти, не камеру), `kit.solid()`, камери `isoCamera()`/`perspCamera()`, IntersectionObserver, visibilitychange, reduced-motion = один статичний кадр, `capDpr`, `webglcontextlost`, `destroy()`.
API: `createIlScene({ host, slots, scenes: { key: (kit) => ({ root, update(phase), staticPhase }) }, canvasClass, period, camera, shrink, staticPhase, beforeRender })` → `{ destroy, draw, addSlot, slots, kit }` або `null` без WebGL; повний JSDoc на початку файлу. Приклади: `src/pages/home-product-scenes.js` (перспектива), `home-quality-scenes.js` (ізо + підлога). Підключення лише ліниво (динамічний `import()` у `main.js`). ## Motion (рух)
- **Токени:** `--dur-fast` 150ms, `--dur` 200ms (старий), `--dur-base` 250ms, `--dur-slow` 600ms, `--ease-out` cubic-bezier(.22,.61,.36,1), `--ease-in-out` cubic-bezier(.65,0,.35,1), `--reveal-distance` 16px, `--stagger` 60ms. Стилі руху: `src/styles/motion.css`, логіка: `src/motion.js`.
- **Правила:** рухаємо лише `opacity` і `transform`; тривалість 150–600 мс; ease-out; без пружин і пульсу; зум фото лише як описано нижче (zoom-out у масці). `prefers-reduced-motion: reduce` вимикає все (reveal, transition, Lenis, view transition).
- **Фото: лише ZOOM-OUT, без opacity (рішення замовника 2026-11-12):** жодне фото/фото-контейнер не з'являється через opacity/translate (на них немає `data-reveal`/`data-reveal-load`, і вони не лежать усередині блока з `data-reveal`). Контейнер-маска (`overflow: hidden`/`clip` + радіус, `isolation: isolate`) нерухомий; `img` усередині отримує клас-батька `.photo-zoom` (додає `motion.js`, `initPhotoZoom`, селектор `PHOTO_MASKS`), стартує зі `scale(var(--photo-zoom-from))` (1.12) і при вході маски у в'юпорт (поріг 0.2) один раз зменшується до 1 за `--dur-zoom` (5000ms, `--ease-out`) класом `.is-zoomed`; `will-change` лише поки триває зум. Без JS і за reduced-motion scale = 1. Нове фото: покласти в маску з `overflow: hidden` і додати її селектор у `PHOTO_MASKS`. Масок: `.photo-panel` (Home), `.svc-supply` (Services), `.about-intro__figure`, `.slide--image`, `.slide__photo`, `.people-card__media` (About), `.contact-split__media` (Contact), `.hero__media` (fallback-фото), `.svc-card__art` (Services, ілюстрація `svg.svc-art` в арт-зоні картки). Для `svg.svc-art`: селектор `html.js .photo-zoom svg.svc-art` (той самий `:is(...)` у `motion.css`) і `PHOTO_EL` у `motion.js` = `img, svg.svc-art`; масштаб 1.12→1 за 5 с, reduced-motion: без зуму. **Фото/медіа без opacity-появи на всіх сторінках (рішення замовника, 2026-11-13):** жодне фото, відео чи медіа-блок (включно з 3D-канвасом `.process-scroll__canvas` на Services) не з'являється з opacity 0; канвас прозорий до першого кадру, тож без fade. Картки `.svc-card` (Services) з арт-зоною `.svc-card__art` (ізо-ілюстрація `svg.svc-art`) — це медіа, тому БЕЗ opacity-появи (рішення замовника 2026-11-13): `article.svc-card` без `data-reveal`; reveal лишився лише на текстових `header.svc-card__head` і `p.svc-card__text` (той самий stagger `data-reveal-delay` 0–3). Ілюстрація зумиться як фото (zoom-out у масці, див. «Фото» нижче).
- **Великі заголовки — пословна поява:** КОЖЕН `h1/h2/h3.t-display` на всіх сторінках (без `data-reveal`/`data-reveal-load` `motion.js` сам додає `data-reveal`, тригер IntersectionObserver; hero — одразу) `motion.js` розбиває на `<span class="word"><span class="word__inner">` (`<br>`, пробіли, вкладені теги й `&shy;` зберігаються; `aria-label` = простий текст, `.word` має `aria-hidden`). Блоковий reveal для них вимкнено (прихований, доки не розбитий). `.is-revealed` запускає слова: `translateY(120%)`+`opacity 0 → 1`, `--dur-slow` (600ms) `--ease-out`, затримка `--reveal-delay + --i * --word-stagger` (`--word-stagger` = `--stagger` × 1.2 = 72ms, локально в `motion.css`); `.word` = `inline-block; overflow: clip` з `padding .15em .06em` і рівним від'ємним margin (низ g/y/p не обрізається, геометрія незмінна, переноси ті самі). Зміна мови: `i18n.js` після перекладу викликає `window.__titleWords()` — слова пересплітаються, вже проявлені одразу в кінцевому стані (`.is-instant`, без повтору). Перша поява чекає перший переклад (≤1.2 с запасний таймер). `prefers-reduced-motion`: без розбиття, текст одразу. Заголовки в sticky/pin-секціях (Process, How we work) теж: рухаються лише `opacity`/`transform` слів, розміри й позиції не змінюються. Новий `.t-display` отримує ефект автоматично. Виняток: `h2[data-scroll-fill]` (Home About): заливка тексту по скролу замість слів (див. About у Home). Якщо предок має блоковий `data-reveal="fade"` (closing, слайди), fade блоку й слова йдуть разом.
- **Smooth scroll:** Lenis (`duration 1.1`, easing expo-out, `window.lenis`); якорі скролять з відступом `--header-h`; на reduced-motion Lenis не стартує, нативні якорі з `scroll-padding-top`. **Заход із hash (`/about.html#about`, з іншої сторінки чи напряму):** `initHashLanding()` (`motion.js`) одразу ставить секцію на `--header-h` (миттєво, без анімації) і УТРИМУЄ позицію (ResizeObserver на `body`, `fonts.ready`, `load`) ще 2 с після `load`; зупиняється на першу взаємодію (wheel/touch/key/pointerdown); `history.scrollRestoration='manual'`; працює й при reduced-motion. - **Reveal:** `data-reveal="up|fade|scale-in"` (за замовчуванням up), `data-reveal-delay="N"` (0–20 = індекс stagger ×`--stagger`, більше = мс), `data-reveal-stagger` на контейнері (діти по черзі, затримка лише для перших 8). - **Перехід між сторінками:** cross-document View Transition (fade 250 мс), `.header__panel` має `view-transition-name: site-header`.
- **Фон-шейдер ізоліній (Product):** `src/pages/product-bg.js` + `src/styles/components/page-bg.css` (`<canvas class="page-bg" aria-hidden>`, fixed, z-index -1). Рендер у НАТИВНІЙ роздільності (canvas = CSS-розмір × DPR, DPR ≤ 2, без апскейлу, патерн у CSS px), ізолінії 1 device px з аналітичним згладжуванням (`fwidth`), ОДИН колір ліній `--accent` з alpha 0.13 на `--surface` (без смуг-заливок, плям, змішування). - **Line (дефолт)**: усі форми на світлому фоні сторінки (контакт, RFQ). Лише токени; стан помилки лише через `--text-error`/`--border-error` (білу рамку на accent більше не використовуємо).

## Dev-інструменти (лише `vite dev`, у збірку не потрапляють)
Рев'ю-оверлей (`dev-tools/review/`, Shadow DOM, `pointer-events: none`) має інспектори, які лише читають DOM сайту:
- `G` «Сітка»: колонки з токенів `--container/--gutter/--grid-cols/--grid-gap`.
- `S` «Стиль»: padding (зелений) і gap flex/grid (помаранчевий) зі значеннями в px; margin не показується.
- `T` «Текст»: `розмір/інтерліньяж · вага · трекінг · клас t-* · шрифт` біля кожного текстового об'єкта.
- `K` «Колір»: колір тексту/фону/рамки з hex і назвою токена (мапа з усіх кольорових кастомних властивостей `:root`; пріоритет семантичних над `--c-*`).
Клавіші читаються по `event.code`; стан зберігається в `localStorage`; деталі в `review/README.md`.
